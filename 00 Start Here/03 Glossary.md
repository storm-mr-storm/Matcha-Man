# Glossary

**Agentic UI** — UI that exposes the work, decisions, handoffs, and state of an autonomous or semi-autonomous system.

**Activity** — what the system is doing right now.

**Badge** — compact noninteractive status/category metadata.

**Card** — a persistent content surface containing one coherent content unit.

**Feedback** — information the user should notice because it affects their understanding or next action.

**Progress** — how far along a bounded process is.

**Semantic token** — a theme-aware variable such as `text/primary` or `status/positive`, used instead of raw primitive colors.

**Status** — the current condition of an entity or process, usually communicated with Badge or text.

**Activity working state** — active work with observable behavior; in Matcha Man this can use the restrained moving-gradient text treatment.

**Product library** — the application UI system documented in this vault.

**Brand library** — the separate marketing/brand system; intentionally out of scope here.

**Robot café world** — the fictional operational example domain used to demonstrate agentic behavior without coupling the design system to finance.
