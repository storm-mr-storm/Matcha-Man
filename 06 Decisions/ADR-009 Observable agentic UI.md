# ADR-009 Observable agentic UI

## Context

Agent interfaces can become theatrical, using vague “thinking” language, glowing animations, and magical AI metaphors.

## Decision

Expose concrete activity, handoffs, decisions, blocks, progress, and important feedback. Use restrained jazz-blue active-work motion.

## Rationale

Users need operational trust and legibility more than anthropomorphic performance.

## Consequences

Reasoning summaries stay at observation → decision level and do not attempt to reveal hidden chain-of-thought.
