# Matcha Man version

Current version: **v0.1.0**

Status: Active development

Version tracking introduced: **2026-09-18**

First formally tracked Matcha Man design-system version. The system existed before version tracking was introduced. Existing ADR-001 through ADR-010 predate release tracking; no historical releases are inferred for them.

## Current release

### v0.1.0

- Formal version tracking introduced alongside the existing ADR governance.
- Radius-aware [[Table]] spacing standardized through [[ADR-011 Radius-aware table spacing]].

See [[06 Decisions/CHANGELOG|CHANGELOG]], [[Decision log]], and [[01 Rule strength and source of truth#Versioning and change records|versioning rules]]. This version records the accepted system specification; it does not certify that every product or Figma component has adopted it.

## Accepted, unreleased guidance

The 2026-09-19 surface-hierarchy extension to [[ADR-011 Radius-aware table spacing]], system-wide clarification of [[ADR-012 Accessible Select listbox implementation]], and [[ADR-013 Metric Card default anatomy]] are accepted and tracked under [[06 Decisions/CHANGELOG|Unreleased]] as a **MINOR candidate**. They are canonical implementation defaults now; Unreleased describes publication status, not optionality.

No new release is cut in this documentation pass. **v0.1.0 remains the current release.** Use [[Product design philosophy#Opinionated defaults]] for the current defaults index; follow the existing release process when publishing a future version.
