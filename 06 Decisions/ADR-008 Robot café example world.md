# ADR-008 Robot café example world

## Context

The system originated from Open Thesis and accumulated finance-specific examples that made the design library feel product-bound.

## Decision

Documentation prose stays generic; examples use a fictional autonomous robot café.

## Rationale

The café provides rich agentic workflows, metrics, status, operational data, and human decision points without coupling the library to finance.

## Consequences

Keep humor restrained and dry. Preserve generic component/token names; never rename components around café metaphors.
