# Menu

**Figma page:** 29 — Menu

Menu is for contextual commands/actions.

## Surface

- Radius: ~16px, 60% smoothing
- Outer padding: 8px
- Typical width: ~220–240px
- Overlay surface + quiet border

## Menu Item

- Height: ~44px
- Horizontal padding: 16px
- Radius: ~12px, 60% smoothing
- States: Default, Hover, Focus, Disabled
- Tone: Default, Destructive

Optional leading Icon and trailing shortcut/chevron are supported. Destructive uses red text/icon, not a full red fill.

## Distinction

Menu performs an action. [[Select]] changes a value. [[Navigation]] changes destination. [[List]] represents content/entities.
