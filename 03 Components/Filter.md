# Filter

**Figma page:** 34 — Filter

Filter narrows an existing set. It is distinct from Search.

## Filter Chip

- Height: 36px
- Radius: 12px, 60% smoothing
- Horizontal padding: 12px
- Neutral surface, not semantic-status color

Example: `Status · Brewing ×`

Key may be quiet secondary; value medium primary. Optional remove uses local Icon.

## Filter Bar

Existing Button trigger + applied chips + optional Clear All. Active count should represent active categories where possible.

## Quick Filters

Use for roughly 3–5 one-click constraints. Quick Filters are not Tabs.

## Filter Panel

Desktop overlay guidance: ~320–400px width, 24px padding, 24px radius / 60% smoothing. Use existing controls such as Checkbox, Radio, Select, and Button.
