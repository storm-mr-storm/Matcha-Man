# Modal and Overlay

**Figma page:** 28 — Modal & Overlay

Modal interrupts the current flow for a focused decision or task. Overlay/Scrim is a separate component.

## Overlay

Approximately 60–70% dim with restrained ~8–12px backdrop blur. Underlying context should remain recognizable.

## Modal

- Radius: 40px, 60% smoothing
- Recommended padding: ~32px
- Standard desktop width: ~440–480px
- Raised/overlay semantic surface
- Quiet 1px border
- No dramatic shadow

## Header

Title + optional quiet X close control. Reuse the approved lightweight close treatment.

## Footer/actions

Use existing Buttons. Preserve the editorial left keyline rather than defaulting to generic right-aligned enterprise dialogs.

Mobile actions MAY stack. Do not invent a separate mobile Modal component solely for width.
