# Tabs

**Figma page:** 16 — Tabs

Tabs switch between sibling views.

## Default visual language

- Underline/indicator treatment, not pills
- 40px height
- 16px horizontal padding
- 4px parent gap
- 2px Matcha selected indicator
- Inter Medium 500

Selected text is primary; unselected text is secondary. Focus uses jazz-blue/info.

## Responsive

Use the same component on Desktop/Mobile. Narrow layouts may use horizontal overflow rather than compressing labels into illegibility.

Do not convert Tabs into Buttons, Badges, or Navigation Items.
