# Radio

**Figma page:** 14 — Radio

Radio is for mutually exclusive choices that benefit from being visible at once.

## Geometry

- Outer circle: 20×20
- Selected inner dot: 8×8
- Label gap: 8px
- Labeled target SHOULD be about 44px

## States

Unselected/Selected × Default/Hover/Focus/Disabled.

Selected treatment uses a Matcha ring and inner dot. Do not fill the entire circle like Checkbox.

## Use over Select when

The option set is small and seeing all choices improves the decision.
